# AISHA HOME V2 frontend
React + Vite demo katalog, savat, checkout va sessiyaga bog‘langan buyurtmalar sahifalari. Demo ma’lumotlar Express va MongoDB’dan olinadi. Buyurtma narxi va qoldiq serverda tekshiriladi; yetkazish summasi namunaviy. Haqiqiy to‘lov, admin autentifikatsiya va CRM mavjud emas.

Lokal ishga tushirish uchun loyiha ildizidagi README.md faylini ko‘ring. Frontend buyruqlari: npm.cmd test, npm.cmd run build, npm.cmd run dev. VITE_API_URL ommaviy qiymat; unga maxfiy ma’lumot qo‘ymang. Rasm manbalari public/demo/SOURCES.md faylida.
